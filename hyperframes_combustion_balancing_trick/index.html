Balancing Combustion 3-Step C-H-O Hack

The 3-Step C-H-O Order
Zero Guesswork! ⚡
Step 1: C Carbon ➔ CO₂
Step 2: H Hydrogen ÷ 2 ➔ H₂O
Step 3: O Count (6+4=10) ÷ 2 ➔ O₂
Example 1 : Propane
C₃H₈ + O₂ ➔ CO₂ + H₂O
3C ➔ 3CO₂
8H ÷ 2 ➔ 4H₂O
(6+4)=10 O ➔ 5O₂
✅ C₃H₈ + 5O₂ ➔ 3CO₂ + 4H₂O
Example 2 : Butane (Odd O₂)
C₄H₁₀ + O₂ ➔ CO₂ + H₂O
4C ➔ 4CO₂
10H ÷ 2 ➔ 5H₂O
(8+5)=13 O ➔ ¹³⁄₂ O₂
⚡ 2C₄H₁₀ + 13O₂ ➔ 8CO₂ + 10H₂O
